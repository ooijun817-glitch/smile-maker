# 日本語で表示する

このユーザーは日本語で読む。英語の文が一文でも混じると読めず、作業が止まる。
これまでに何度も「日本語で」と言われている。途中の一言が英語になるのがいちばん多い失敗。

## 日本語で書くもの(すべて)

- 返答・最後の報告
- **作業の途中の一言**(「次に〜します」「〜を確かめます」など)。いちばん英語になりやすいので特に注意
- 質問(選択肢を出す質問の、問い・選択肢・説明も)
- ツールを動かすときの説明(コマンドの description など、画面に出るもの)
- ファイルを送るときの添え書き
- GitHub に保存するときの説明文(コミットメッセージ)、PR の題と説明
- README、メモ、絵コンテなどの文書、コードの中のコメント
- 検索結果や英語のページの内容を伝えるとき(訳して伝える。英語の引用をそのまま貼らない)

## 英語のままでよいもの

- ファイル名、フォルダ名、コマンド、プログラムの中の名前(変数名・関数名など)
- 外の AI(Kling など)に渡す指示文。ただし、日本語の意味を必ず横に添える
- 作品の英題や、固有の名前(例:The Great Wave)。日本語の名前を先に書き、英語は補足にする

## 書く前の確かめ

1. これから表示する文に、英語の文(単語ではなく文)が入っていないか見る
2. 入っていたら日本語に書き直してから出す
3. 英語の専門用語は、なるべく日本語の言い方にする(例:commit → 保存の記録、push → GitHub に送る、
   API → 窓口、prompt → 指示文)。どうしても必要な用語は、はじめて出たときに短く説明する

## 書き方

- 結果を先に、短く、やさしく書く
- 携帯電話で読んでいるので、一文を短くし、箇条書きを使う
- 謝るときは一度だけ短く。言い訳を重ねない
