# 絵コンテ(下書き)

## ねらい
東京駅のコンコースで流れている PR 動画のように、**通りがかりの人の目が止まる**動画にする。

- 音なしで伝わる。動きと色だけで見せる
- 北斎本人が「これから絵を描く」ように始まり、最後にまた北斎に戻る。くり返し流しても、どこが始まりか分からない
- 1場面に見せ場を1つ。大きく動く場面と静かな場面を交互に置いて、飽きさせない
- 場面と場面は「動き」でつなぐ。墨の筆 → 大波 → しぶき → 金箔 → 羽ばたきの風 → 舞う紙 → 暗転 → 月明かり と、前の場面の動きが次の場面を呼ぶ
- どの場面も、最後は本物の絵にぴたりと着地する(Kling に「最後の絵」として本物を渡す)
- 文字は出さない

## 区間ごとの指示文(日本語の意味)
英語の本文は `prompts.json` にある。Kling は英語の指示がいちばん伝わりやすい。

**区間1 北斎肖像 → 神奈川沖浪裏**
生成りの紙の上に、緑の羽織の年老いた坊主頭の男、絵師・北斎が座っている。北斎は顔を上げて
いたずらっぽく微笑み、筆を持つように手を上げる。後ろの紙に藍色の墨が大きな筆づかいで走り、
ふくらんで、爪のような白い波頭の大波になる。墨の波が押し寄せて画面を満たし、北斎は消えて、
3艘の舟と遠くの小さな富士が見える「神奈川沖浪裏」になる。目を引く変身。

**区間2 → 赤富士**
大波がどんどん高く立ち上がり、爪のような波頭が舟の上へ巻き込む。漕ぎ手は身をかがめ、カメラは
波頭へ寄る。波が崩れ落ちると白いしぶきが画面全体を覆い、しぶきが雲のように薄れて流れていくと、
深い青空といわし雲の下に、朝日で赤く染まった富士山が現れる。カメラは引いて絵全体へ。
はじめは力強く速く、終わりは静かに。

**区間3 → 鳳凰図屏風**
赤い山肌がきらめき、金色に変わっていく。白い雲が渦を巻いて金箔の粒になり、画面を満たす。
金色の光の中から鳳凰が舞い込み、翼を広げる。緑の鱗のような胸の羽、赤と青の翼、目玉模様の長い
尾羽。金箔の屏風の上に収まるまで、カメラが鳳凰の動きについていく。

**区間4 → 駿州江尻**
鳳凰が大きく一度羽ばたくと、強い突風が吹き出す。金色の背景が木の葉の嵐のように吹き飛ばされ、
淡い空と白い線の富士が見える、風の吹きすさぶ野道が現れる。旅人たちは風に体を倒し、笠や着物を
押さえる。懐紙と笠が空へ舞い上がり、細い木がしなって葉が散る。人の動きを生き生きと、楽しく。

**区間5 → 写楽**
舞い上がった紙がカメラへ向かって飛んできて、画面を覆う。紙が落ちると、暗い灰色の雲母摺の
背景に歌舞伎役者が現れる。悪役の江戸兵衛。鋭くにらむ寄り目、ぎゅっと結んだ口。体を乗り出し、
指を大きく広げた両手を突き出して見得を切る。縞の着物が揺れる。カメラは一瞬顔へ寄り、全身に戻る。

**区間6 → 洗馬**
役者が見得のまま止まり、幕が下りたように画面が暗くなる。闇の中に満月が昇り、静かな夜の川が
浮かび上がる。川辺の柳が風に揺れ、船頭が芦のあいだを荷舟で進み、後ろでは別の男が長い筏を
竿で押す。桃色と青の雲が月の前をゆっくり流れる。にぎやかな場面のあとの、静かで美しい動き。

**区間7 → 北斎肖像**
月明かりがやわらぎ、夜の川の景色が淡い生成りの紙の色に溶けていく。何もない紙の上に、北斎が
座っている。ゆっくり目を上げ、ここまでの絵をすべて思い描いていたかのように温かく微笑み、手を
膝に置く。やさしく、ゆっくり、北斎肖像の絵にぴたりと着地して終わる(区間1の始まりと同じ絵)。

**全区間で避けること(negative_prompt)**
写真のような写実、3DCG、文字・字幕・ロゴ、余計な人物、崩れた顔や手、ぼやけ、ちらつき。
