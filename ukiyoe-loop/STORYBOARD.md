# 絵コンテ(下書き)

## ねらい
駅のコンコースのデジタルサイネージのように、通りがかりの人の目が止まる動画にする。
軸は3つ。

- **趣きある日本**:浮世絵の線・色・和紙の質感はそのまま。品よく、落ち着いた空気を保つ
- **現代らしさ**:今の映像広告の見せ方を取り入れる。カメラの寄り引き、奥行きの重なり
  (手前と奥が違う速さで動く)、画面を横切る光、場面を切り替える「ぬぐい」の動き、
  きびきびした間合い
- **生きるが如く**:絵の中のものが本当に生きているように、大きく力強く動く

約束ごと:
- 音なしで伝わる。動きと色だけで見せる。文字は出さない
- 人物は笑わせない。表情は静か、または芝居の鋭さ
- 1場面に見せ場を1つ。大きく動く場面と静かな場面を交互に置いて、緩急をつける
- 場面と場面は「動き」でつなぐ。墨の一筆 → 大波 → しぶき → 光と金箔 → 羽ばたきの風 →
  舞う紙 → 暗転 → 月明かり と、前の場面の動きが次の場面を呼ぶ
- 八方睨み鳳凰図の「どこから見ても目が合う」眼差しを、通りがかりの人と目が合う瞬間として使う
- どの場面も、最後は本物の絵にぴたりと着地する(Kling に「最後の絵」として本物を渡す)
- 北斎に始まり北斎に戻るので、くり返し流してもどこが始まりか分からない

## 区間ごとの指示文(日本語の意味)
英語の本文は `prompts.json` にある。Kling は英語の指示がいちばん伝わりやすい。

**区間1 北斎肖像 → 神奈川沖浪裏**
生成りの紙の上に、緑の羽織の年老いた坊主頭の絵師・北斎が、静かに集中した面持ちで座っている。
頭は最後まで坊主頭のまま(頭の上には何も描かれない)。筆を持つ手を上げ、さっと一振りすると、
藍色の墨の一筆が、北斎の横と後ろの白い紙の上を左から右へ走る。一筆はふくらみ、立ち上がり、
爪のような白い波頭の大波になる。大波は押し寄せて北斎ごと画面を飲み込む(薄く重ねて切り替える
のではなく、ひと続きの動きで画面をぬぐう)。水が過ぎると、3艘の舟と遠くの小さな富士が見える
「神奈川沖浪裏」になる。カメラは奥行きを持って前へ進む。
(1回目の試作で、墨が髪のように頭に描かれ、場面が薄く重なって切り替わったため、そうならないよう指示を足した)

**区間2 → 赤富士**
大波が生きているかのように高く立ち上がり、爪のような波頭が舟の上へ巻き込む。漕ぎ手は低く身構え、
カメラは波頭へ寄る。波が崩れ落ちると、白いしぶきが画面をぬぐうように横切る。しぶきが幾重にも
流れ去ると、深い青空といわし雲の下に、朝日で赤く染まった富士山が現れる。朝の光が赤い山肌を
すっと走り、カメラは引いて絵全体へ。

**区間3 → 八方睨み鳳凰図**
朝の光が赤富士の山肌を走り、金色に変える。白い雲が砕けてきらめく金箔になり、奥行きを持って
カメラへ漂ってくる。金色の中から鳳凰が現れ、金箔の天井板の上で大きな輪を描く。羽が一枚ずつ開く。
緑の鱗のような羽、赤と青の翼、金の目玉模様の長い尾羽、まわりを囲む緑の葉。鳳凰が首を巡らせ、
鋭い目が見る人をぴたりと射抜く(どの方向から見ても目が合う「八方睨み」)。カメラは天井の下を
歩くように少し回り込み、絵の全体で止まる。

**区間4 → 駿州江尻**
鳳凰が翼を広げ、力強く一度羽ばたくと、風が吹き出す。金箔の地が嵐の木の葉のように幾重にもはがれ、
淡い空と白い線の富士が見える、風の吹きすさぶ野道が現れる。旅人たちは風に体を倒し、着物を
はためかせ、笠を押さえる。懐紙と笠が渦を巻いて空へ舞い上がり、細い木がしなって葉を散らす。
カメラは曲がる野道に沿って低く進み、手前の草が勢いよく流れていく。

**区間5 → 写楽**
舞い上がった紙がカメラへ押し寄せ、画面をぬぐうように覆う。紙が落ちると、暗い灰色の雲母摺の
背景に歌舞伎役者が現れる。悪役の江戸兵衛。鋭くにらむ眼差しと、ぎゅっと結んだ口。見得を切る瞬間、
目が寄り、指を大きく広げた両手が前へ突き出され、縞の着物が振れる。カメラは顔へ一瞬ぐっと寄り、
全身で止まる。芝居の鋭さと迫力。

**区間6 → 洗馬**
役者が見得のまま止まり、幕が下りたように画面が闇に落ちる。闇の中に淡い満月が昇り、静かな夜の川が
現れる。川辺の柳が風に揺れ、船頭が芦のあいだを荷舟で進み、後ろでは別の男が長い筏を竿で押す。
桃色と青の雲が月の前をゆっくり流れる。カメラは横へゆっくり動き、芦・柳・空がそれぞれ違う速さで
重なり合う。静かで品があり、生きている。

**区間7 → 北斎肖像**
月明かりがやわらぎ、夜の川が淡い生成りの紙の色に溶けていく。何もない紙の上に、北斎が静かで
威厳のある面持ちで座り、遠くを見つめている。羽織が風にわずかに揺れ、手が膝に落ち着く。カメラが
ゆっくり止まり、北斎肖像の絵にぴたりと着地して終わる(区間1の始まりと同じ絵)。

**全区間に付ける作風の指示**
大きな駅のコンコースのデジタルサイネージ向けの映像。ダイナミックなカメラワーク、手前と奥が
重なる奥行き、きびきびした間合い、品のある日本の空気。すべてが生きているように動く。浮世絵らしい
くっきりした墨の線、平らな色、和紙の質感を保ち、写実的な陰影は付けない。

**全区間で避けること(negative_prompt)**
笑顔・にやけ顔・笑い、漫画やアニメ調、写真のような写実、3DCG、写実的な光やレンズの光の筋、
文字・字幕・ロゴ、余計な人物、崩れた顔や手、指の数の誤り、ぼやけ、ちらつき。
