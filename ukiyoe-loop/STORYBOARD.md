# 絵コンテ(下書き)

## ねらい
駅のコンコースのデジタルサイネージのように、通りがかりの人の目が止まる動画にする。
軸は3つ。

- **趣きある日本**:浮世絵の線・色・和紙の質感はそのまま。品よく、落ち着いた空気を保つ
- **現代らしさ**:今の映像広告の見せ方を取り入れる。カメラの寄り引き、奥行きの重なり
  (手前と奥が違う速さで動く)、画面を横切る光、場面を切り替える「ぬぐい」の動き、
  きびきびした間合い
- **生きるが如く**:絵の中のものが本当に生きているように、大きく力強く動く

約束ごと:
- 音なしで伝わる。動きと色だけで見せる。文字は出さない
- 人物は笑わせない。表情は静か、または芝居の鋭さ
- 1場面に見せ場を1つ。大きく動く場面と静かな場面を交互に置いて、緩急をつける
- **隣どうしの絵に共通点があるように並べる**。AI は、色も中身もまったく違う2枚のあいだを
  「描き足して変える」より「薄く重ねて切り替える」ほうを選びがち。共通点(富士、赤と金、目、人物、
  風、水と舟)を手がかりに、ひと続きの動きで次の絵へ変える
- 八方睨み鳳凰図の「どこから見ても目が合う」眼差しを、通りがかりの人と目が合う瞬間として使う
- どの場面も、最後は本物の絵にぴたりと着地する(Kling に「最後の絵」として本物を渡す)
- 最後の区間は最初の絵(神奈川沖浪裏)に着地するので、くり返し流してもどこが始まりか分からない

## 区間ごとの指示文(日本語の意味)
英語の本文は `prompts.json` にある。Kling は英語の指示がいちばん伝わりやすい。
どの区間にも「ひと続きの変化で、薄く重ねて切り替えない」と書いている。

**区間1 神奈川沖浪裏 → 赤富士**
大波が生きているかのように高く立ち上がり、爪のような波頭が舟の上へ巻き込む。漕ぎ手は低く身構え、
カメラは波頭へ寄る。波が砕けると、白いしぶきが空へ舞い上がり、広がって、深い青空に並ぶいわし雲に
なる。海が引いていき、遠くの小さな雪の富士が、朝日で赤く染まった大きな山へとそびえ立つ。朝の光が
赤い山肌をすっと走り、カメラは全体で止まる。

**区間2 → 八方睨み鳳凰図**
朝の光が赤富士の山肌を走り、赤が朱・橙・金へと燃えるように深まる。白い雲が砕けてきらめく金箔になる。
赤い山の斜面が折り重なり、巻いて、鳳凰の大きな羽の体になる。緑の鱗のような羽、赤と青の翼、金の目玉
模様の長い尾羽、まわりを囲む緑の葉。金箔の寺の天井板の上で、輪を描いて収まる。鳳凰が首を巡らせ、
鋭い目が見る人をぴたりと射抜く。カメラは天井の下を歩くように少し回り込む。

**区間3 → 写楽**
鳳凰の鋭い目が見る人をにらみ、カメラはその目へぐっと寄って、目が画面いっぱいになる。鳥の目が、
歌舞伎役者の寄り目のにらみに変わる。カメラが引くと、暗い灰色の雲母摺を背に、口をぎゅっと結んだ
悪役の江戸兵衛が現れる。見得を切り、指を大きく広げた両手を前へ突き出し、縞の着物が振れる。
鳳凰の色とりどりの羽は、着物の縞に折りたたまれる。芝居の鋭さと迫力。

**区間4 → 北斎肖像**
役者は見得のまましばらく止まり、ゆっくりほどく。広げた手が下りて膝に落ち着き、こわばった肩がゆるみ、
にらみは静かに集中した眼差しになる。髷と髪が消えて坊主頭になり、縞の着物はやわらかな緑の羽織に
なる。暗い灰色の背景は、淡い生成りの紙の色に明るくなる。役者は、静かで威厳のある面持ちで座る、
年老いた絵師・北斎になる。

**区間5 → 駿州江尻**
北斎は淡い紙の上に静かに座り、遠くを見つめている。風が起こり、緑の羽織がはためき、まわりの紙が
宙に浮き上がる。風は強い突風になって画面を吹き抜け、生成りの紙が、白い線の富士が見える淡い空と
風の吹きすさぶ野道に開ける。旅人たちは風に体を倒し、着物をはためかせ、笠を押さえる。紙と笠が渦を
巻いて空へ舞い上がり、細い木がしなって葉を散らす。カメラは曲がる野道に沿って低く進む。

**区間6 → 洗馬**
野を風が吹き続け、しなった木が揺れて葉が流れていく。日が暮れ、淡い空が夕方の青へ深まり、揺れる木の
向こうに満月が昇る。木は柳になる。曲がる野道は、芦のあいだを流れる静かな川になる。船頭が荷舟を竿で
進め、もう一人が長い筏を押す。桃色と青の雲が月の前をゆっくり流れる。カメラは横へゆっくり動き、
芦・柳・空が違う速さで重なる。静かで美しい。

**区間7 → 神奈川沖浪裏**
満月の下で川がふくらみはじめる。流れが強まり、船頭は竿に体を預け、水は白い泡を立てて、だんだん
大きな波になる。夜空は淡い夜明けに明るくなり、月は沈んで、遠くの小さな雪の富士になる。ふくらんだ
水は、爪のような波頭が長い舟の上に巻き込む大波へと立ち上がり、「神奈川沖浪裏」になる。カメラは
立ち上がる水とともに前へ進む。

**全区間に付ける作風の指示**
大きな駅のコンコースのデジタルサイネージ向けの映像。ダイナミックなカメラワーク、手前と奥が
重なる奥行き、きびきびした間合い、品のある日本の空気。すべてが生きているように動く。浮世絵らしい
くっきりした墨の線、平らな色、和紙の質感を保ち、写実的な陰影は付けない。

**全区間で避けること(negative_prompt)**
笑顔・にやけ顔・笑い、漫画やアニメ調、写真のような写実、3DCG、写実的な光やレンズの光の筋、
文字・字幕・ロゴ、余計な人物、崩れた顔や手、指の数の誤り、ぼやけ、ちらつき。
