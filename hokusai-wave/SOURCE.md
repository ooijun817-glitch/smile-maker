## 使い方のメモ

- CC0 のため、表示・加工・再配布に許可や表記の義務はない。それでも出どころはこのファイルに残しておく。
- アプリの中では文字を出さない方針なので、クレジットはこのファイルと README に置く。
- `assets/great-wave.jpg` は上の画像ファイルを長辺 3000px に縮めたもの(`tools/build_assets.py` で作成)。絵そのものには手を加えていない。
