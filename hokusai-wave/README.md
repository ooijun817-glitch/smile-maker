# 神奈川沖浪裏(試作)

葛飾北斎「神奈川沖浪裏」を、ごくゆっくり動かして流すだけの画面。
iPhone を夜に半分開いて立て、枕元で眺めるためのもの。

- 絵は一枚のまま使い、切り分けない
- 「大波」「波の先」「海面」「空」の範囲を、大きくぼかした白黒マスクで決める
- 範囲ごとにシェーダーで絵をわずかに歪ませる(色は変えないので線はにじまない)
- 30 秒で一周。動きは位相の整数倍だけで書いているので、つなぎ目が出ない
- 富士山は動かさない
- 画面には絵だけ。Screen Wake Lock で画面が消えないようにする

## 作り方は2つある

| ページ | 作り方 | 向き不向き |
| --- | --- | --- |
| `index.html`(いまの本命) | 元の絵から AI(Figma Weave の Kling)で動画を作り、くり返し流す。最初と最後のコマを元の絵にそろえてつなぎ目を消す | 波が流れる、しぶきが飛ぶなど大きく動かせる。線は AI が描き直したものになる |
| `warp.html` | 一枚の絵をマスクで決めた範囲ごとにシェーダーで曲げる | 北斎の線はそのまま。動きは「曲げる」範囲にとどまる |

参考にしたイメージ:YouTube「浮世絵が動き出した結果」(@NEO-UKIYO-E)のような、絵そのものが動き出す見え方。

## 進み具合(warp.html)

1. 大波のうねり(済み。大きめに調整)
2. 海面の上下(小舟も一緒に)
3. 空の雲の流れ

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `player.js` | AI 動画を全画面でくり返し流す。画面を消さない処理 |
| `assets/great-wave-loop.mp4` | AI で作った動画 |
| `warp.html` / `app.js` | シェーダー版。WebGL シェーダー、30 秒ループ、画面を消さない処理 |
| `assets/great-wave.jpg` | 絵(長辺 3000px) |
| `assets/masks.png` | 範囲マスク(R=大波 / G=波の先 / B=海面) |
| `tools/build_assets.py` | 絵の縮小とマスク作成 |
| `SOURCE.md` | 絵の出どころとライセンス |

## 調整用の隠しオプション(URL に付ける)

- `?debug=mask` マスクを色で重ねて表示
- `?speed=4` 早送り(一周のつなぎ目の確認用)
- `?amp=2` 揺れ幅を倍に

## 絵の出どころ

メトロポリタン美術館所蔵、Open Access(CC0 / パブリックドメイン)。詳しくは [SOURCE.md](SOURCE.md)。
